
# Redux Toolkit Todo App

A Todo application built with **React, Redux Toolkit, and React-Redux** to manage tasks using centralized state management. This project demonstrates how Redux Toolkit simplifies state updates and how React components interact with the Redux store.

## 🚀 Features

- **Add Todos:** Create new tasks.
- **Display Todos:** View your list of tasks.
- **State Management:** Manage Todo data using Redux Toolkit.
- **React-Redux Integration:** Access and update the Redux store from React components.
- **Responsive Styling:** Style the user interface using Tailwind CSS.

## 🛠️ Technologies Used

- React.js
- Vite
- Redux Toolkit
- React-Redux
- Tailwind CSS
- JavaScript
- HTML5 and CSS3

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/mrk-codes/todo-Reduxtookit-and-react-redux.git
```

**2. Navigate to the project folder**

```bash
cd todo-Reduxtookit-and-react-redux
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.
